# Experience vs. Salary Prediction (Linear Regression)

## Overview
This project demonstrates a simple Machine Learning pipeline using **Python**, **Pandas**, **Matplotlib**, and **Scikit-Learn** to predict a person's salary based on their years of experience using **Linear Regression**.

---

## Dataset Summary
- **Features (X):** Years of Experience  
- **Target (Y):** Salary  
- **Preprocessing:**  
  - Filled missing values using column mean imputation  
  - Removed duplicate rows  

---

## Technologies Used
- Python  
- Pandas  
- NumPy  
- Scikit-Learn  
- Matplotlib  

---

## Steps
1. Create a DataFrame with experience and salary data  
2. Handle missing values and remove duplicates  
3. Perform Exploratory Data Analysis (EDA)  
   - Line plots  
   - Statistical metrics (mean, median, std, correlation)  
4. Split dataset into training and testing sets  
5. Train the Linear Regression model  
6. Evaluate performance using **R² Score**  
7. Predict salaries for test samples and custom inputs  

---

## Model
- Algorithm: **Linear Regression** (Scikit-Learn)  
- Task: Predict salary based on years of experience  

---

## Results
- Model evaluated using **R² Score**  
- Predictions generated for test data and user-defined inputs  

---

## 📌 About
A machine learning project implementing Linear Regression in Python to analyze and predict salaries based on years of experience.
